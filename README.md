# ORC.SEC — Силова служба безпеки

Навчальний багатосторінковий сайт вигаданої охоронної компанії, у якій працюють бойові орки та броньовані тролі. Стилістика — темний «терміналний» інтерфейс з фентезійним відтінком.

Сайт статичний: HTML, CSS та чистий JavaScript, без збірки й залежностей.

## Що реалізовано

1. **Ефект друкарської машинки.** Заголовок «БЕЗПЕКА, ЗАГАРТОВАНА В ПЕКЛІ» з'являється по літері, поруч блимає курсор. Так само друкується рядок `SYS.LOC // 66.6°N 13.0°E` у підвалі. Елементи підключаються атрибутом `data-typewriter` (швидкість і затримка задаються через `data-typewriter-speed` та `data-typewriter-delay`). При `prefers-reduced-motion` анімація вимикається.
2. **Живий статус.** Рядок `STATUS: SECURED` періодично змінюється за циклом `SCANNING...` → `THREAT DETECTED` → `SECURED`, під час загрози колір стає червоним, потім повертається. Також є лічильник аптайму. 
4. **Модальне вікно «Укласти пакт».** Кнопка на головній сторінці відкриває вікно з формою (ім'я, послуга, кількість орків і тролів). Під час відправки показується «Підпис кров'ю…», після цього — повідомлення про успіх.
5. **Глітч при наведенні.** На кнопках і пунктах меню при наведенні виникає короткий глітч-ефект. Поки курсор не наведено, дизайн не змінюється.

## Запуск

Збірка не потрібна: відкрийте `index.html` у браузері. Зручніше запускати через локальний сервер, наприклад розширення **Live Server** у VS Code або команду:

```bash
python3 -m http.server 8000
```

Після цього сайт буде доступний за адресою `http://localhost:8000`.
