# ORC.SEC — Силова служба безпеки

Навчальний багатосторінковий сайт вигаданої охоронної компанії, у якій працюють бойові орки та броньовані тролі. Стилістика — темний «терміналний» інтерфейс з фентезійним відтінком.

Сайт статичний: HTML, CSS та чистий JavaScript, без збірки й залежностей.

## Що реалізовано

1. **Ефект друкарської машинки.** Заголовок «БЕЗПЕКА, ЗАГАРТОВАНА В ПЕКЛІ» з'являється по літері, поруч блимає курсор. Так само друкується рядок `SYS.LOC // 66.6°N 13.0°E` у підвалі. Елементи підключаються атрибутом `data-typewriter` (швидкість і затримка задаються через `data-typewriter-speed` та `data-typewriter-delay`). При `prefers-reduced-motion` анімація вимикається.
2. **Живий статус.** Рядок `STATUS: SECURED` періодично змінюється за циклом `SCANNING...` → `THREAT DETECTED` → `SECURED`, під час загрози колір стає червоним, потім повертається. Також є лічильник аптайму. 
4. **Модальне вікно «Укласти пакт».** Кнопка на головній сторінці відкриває вікно з формою (ім'я, послуга, кількість орків і тролів). Під час відправки показується «Підпис кров'ю…», після цього — повідомлення про успіх.
5. **Глітч при наведенні.** На кнопках і пунктах меню при наведенні виникає короткий глітч-ефект. Поки курсор не наведено, дизайн не змінюється.

## Вимога стейкхолдера №19: часткове врахування
 
**Вимога.** Назви розділів мають виглядати динамічно: перша літера кожного слова в заголовках фарбується в окремий яскравий колір із палітри.
 
**Рішення: «Компромісний рефакторинг».** Ми зберегли мету вимоги (динамічність і яскраві акценти з палітри), але змінили механізм. Замість фарбування літер кожен розділ отримав власний акцентний колір, за яким працює навігація: «колір = розділ».
 
| Розділ | Колір | HEX |
|---|---|---|
| Головна | red | `#8b1e1e` |
| Про нас | purple | `#7a5c89` |
| Послуги | green | `#5c8974` |
| Наші орки та тролі | amber (новий токен) | `#c9a24a` |
 
- Кожен пункт меню має іконку у своєму акцентному кольорі, текст пунктів меню залишився одного кольору.
- Той самий колір використано в мітці над заголовком сторінки (`.text-over-title`).
- Колір розділу зберігається як CSS-змінна `--section-color` (разом із `--section-label-color`), яка задається за атрибутом `data-section` у `css/base.css`.
- Янтарний колір додано тому, що розділів чотири, а акцентів у палітрі три. На шапці він дає контраст 4.21:1.
  
**Чому не буквальна реалізація.**
 
- **Читабельність:** різнокольорові літери руйнують цілісність слова й сповільнюють сканування меню.
- **Доступність (WCAG 2.1, критерій 1.4.3):** на фоні шапки `#4a412a` red дає контраст 1.11:1, purple 1.79:1, green 2.54:1, тобто навіть поріг 3:1 для великого тексту не виконано. Для порівняння, кремовий текст меню `#e8e3d9` дає 7.89:1.
- **Доступність (критерій 1.4.1):** інформація не передається лише кольором, бо колір завжди супроводжується текстом і формою іконки.
- **Інформативність:** колір першої літери («Г», «П», «П», «Н») нічого не повідомляє про зміст розділу.
- **Адаптивність:** на мобільних дрібні кольорові літери ще менш помітні, а іконка лишається розпізнаваною на будь-якій ширині.
- **Стиль:** фірмовий стиль ORC.SEC побудований на стриманій палітрі, а випадкові яскраві літери конкурували б із головною кнопкою «Зв'язок».
  
**Результат.** Стейкхолдер отримав яскравість і динаміку, а користувач навігаційну систему без втрати читабельності, доступності й адаптивності.

## Запуск

Збірка не потрібна: відкрийте `index.html` у браузері. Зручніше запускати через локальний сервер, наприклад розширення **Live Server** у VS Code або команду:

```bash
python3 -m http.server 8000
```

Після цього сайт буде доступний за адресою `http://localhost:8000`.
